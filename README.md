# Шпион

Pass & Play веб-приложение для настольной игры «Шпион»: один телефон, все роли по очереди. Подходит для компании от 3 человек — без регистрации и интернета после загрузки страницы.

## Как играть

1. Добавьте имена игроков (минимум 3).
2. Выберите тематику — локации, предметы, профессии и др.
3. Нажмите **Начать игру** — приложение случайно выберет секретное слово и одного шпиона.
4. Передавайте телефон по очереди: каждый игрок видит свою роль.
   - **Обычный игрок** — секретное слово темы.
   - **Шпион** — не знает слово и должен угадать его по вопросам других.
5. Когда все узнали роли — начинайте обсуждение и голосование вживую.

## Быстрый старт

Требуется [Node.js](https://nodejs.org/) 18+.

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`. Флаг `--host` в скрипте `dev` позволяет подключаться с других устройств в локальной сети — удобно, если телефон и компьютер в одной Wi‑Fi сети.

### Сборка для продакшена

```bash
npm run build
npm run preview
```

Готовые файлы появятся в папке `dist/`.

## Стек

- [Vite](https://vite.dev/) — сборка и dev-сервер
- Vanilla JavaScript + CSS — без фреймворков
- JSON-файлы в `public/` — темы и слова

## Темы и слова

Каталог тем описан в `public/db.json`:

```json
[
  { "name": "Локации", "file": "locations.json" },
  { "name": "Предметы", "file": "items.json" }
]
```

Каждый файл темы — JSON-массив строк:

```json
["Аэропорт", "Банк", "Библиотека"]
```

Чтобы добавить новую тему:

1. Создайте файл `public/my-theme.json` со списком слов.
2. Добавьте запись в `public/db.json`.
3. При необходимости укажите эмодзи по умолчанию в `THEME_DEFAULTS` в `src/main.js`.

## Хранение данных

Список игроков сохраняется в `localStorage` браузера (ключ `spy-game-players`) — при следующем визите имена подставятся автоматически.
